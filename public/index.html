Vercel Serverless REST API Documentation
This project deploys a zero-maintenance Python API on Vercel Serverless Functions:

1. Single Prediction Endpoint: POST /api/predict

curl -X POST "https://your-app.vercel.app/api/predict" \
  -H "Content-Type: application/json" \
  -d '{"text": "Congratulations! You have won a prize. Claim now.", "threshold": 0.5, "explain": true}'

2. Python Integration (requests)

import requests

url = "https://your-app.vercel.app/api/predict"
payload = {
    "text": "URGENT: claim your free reward today!",
    "threshold": 0.5,
    "explain": True
}
response = requests.post(url, json=payload).json()
print("Prediction:", response["predicted_label"])
print(f"Confidence: {response['confidence']:.2%}")

3. JavaScript / Frontend Integration (fetch)

const res = await fetch("/api/predict", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ text: "Are we still meeting at 5 pm?" })
});
const data = await res.json();
console.log(data.predicted_label, data.confidence);

4. How to Deploy to Vercel

# 1. Login to your Vercel account
npx vercel login

# 2. Deploy in one command from repository root
npx vercel --prod
